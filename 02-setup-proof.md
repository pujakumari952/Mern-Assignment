Setup Proof (VS Code, Node.js, Live Server)
Setup proof means showing that the required tools are successfully installed and working.
1. VS Code: Install Visual Studio Code to write and edit HTML, CSS and JavaScript code.
2. Node.js: Install Node.js to run JavaScript outside the browser.
3. Live Server: Install the Live Server extension in VS Code to open and preview webpages in a browser.
4. Create a Project: Create a folder and add an index.html file.
5. Run the Project: Open the HTML file using Live Server and check whether the webpage works correctly.
