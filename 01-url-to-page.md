When we type a URL in a browser and press Enter, several steps happen:
1. URL Parsing: The browser understands the website address and identifies the required page.
2. DNS Lookup: DNS converts the domain name into an IP address.
3. Server Connection: The browser connects to the website's server.
4. HTTP Request: The browser sends a request to the server for the webpage.
5. Server Response: The server sends the requested files, such as HTML, CSS and JavaScript.
6. Rendering: The browser processes these files, displays text, images and design, and shows the final webpage.
