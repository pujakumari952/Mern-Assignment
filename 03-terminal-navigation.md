
| # | Command | Explanation |
|---|---|---|
| 1 | `pwd` | Shows the current folder location. |
| 2 | `ls` | Displays files and folders. |
| 3 | `ls -la` | Shows all files, including hidden files, with details. |
| 4 | `mkdir practice` | Creates a folder named practice. |
| 5 | `cd practice` | Opens the practice folder. |
| 6 | `touch index.html` | Creates an empty HTML file. |
| 7 | `mkdir -p css/images` | Creates nested folders. |
| 8 | `cd ..` | Moves one folder level up. |
| 9 | `cd ~` | Opens the home directory. |
| 10 | `cp index.html backup.html` | Copies a file. |
| 11 | `mv backup.html old.html` | Renames or moves a file. |
| 12 | `rm old.html` | Deletes a file. |
| 13 | `rm -r css` | Deletes a folder and its contents. |
| 14 | `cat index.html` | Displays file contents. |
| 15 | `clear` | Clears the terminal screen. |
| 16 | `code .` | Opens the current folder in VS Code. |
